# TrollHack Recode

TrollHack 的 Minecraft 26.2 / Fabric 重写版本，使用 Kotlin 和 Java 25 构建。

## 构建环境

- Minecraft 26.2
- Fabric Loader 0.19.3 或更高版本
- Fabric API 0.152.1+26.2
- Fabric Language Kotlin 1.13.12+kotlin.2.4.0
- JDK 25

在仓库根目录执行：

```powershell
./gradlew build
```

构建产物位于 `build/libs/`。
